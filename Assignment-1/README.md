# Smart Utility Toolkit

This project is created as part of the Web Development III (Node.js & Express Backend) lab assignment.

The project contains different small utilities built using Node.js built-in modules.

## Technologies Used

- Node.js
- JavaScript
- HTTP
- File System (`fs`)
- Crypto (`crypto`)

No external npm packages are used.
